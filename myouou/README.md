# 守護明王診断

第6回 ぶち癒しフェスタin東京（2026年9月19日）の集客企画。
神様診断 → 天使診断 に続くシリーズ三作目。

公開URL: `https://buchiiyashifestatokyo.com/myouou/`

目的は2つ。

1. LINE公式アカウントの友だち登録を増やす
2. イベント来場を促す

導線は 回答完了 → 簡易結果をその場で表示 → LINE登録 → 番号（1〜4）を送信 →
詳細結果と不動明王のエネルギー画像を配布。

## 設計の芯（崩さないところ）

**四方が結果、中央が特典。**
五大明王は不動明王を中心に、東＝降三世・南＝軍荼利・西＝大威徳・北＝金剛夜叉を配するのが基本形。
この構造をそのまま使い、四方の四体を診断結果、中央の不動明王をプレゼントにしている。
「あなたの明王は四方のどれか。それを束ねる中央に座すのが不動明王」という理屈で、
かんめいさんのエネルギー画像が構成上の五体目になる。

**診断はそれ単体で完結してポジティブに終わる。**
エネルギー画像は結果を高める増幅装置として後から乗る。
画像がないと未完成に見える構成（＝問題を見つけて画像で解決する形）は不採用。

**二段構え。**
診断結果（タイプ名＋説明＋明王の画像）はその場で見せる。
詳細結果と不動明王のエネルギー画像はLINE登録後。
全部を登録の後ろに隠すと離脱する。全部先に見せると登録する理由が消える。ここは動かさない。

**忿怒相の説明はLPの最上部。**
「怖い顔＝怒り」の印象を先に外しておかないと、結果が前向きに読まれない。
`index.html` の `.funnu-note` がそれ。位置を下げないこと。

**特典は画像1枚のみ。**
かんめいさんのエネルギー画像が、そのまま会場で使えるクーポンを兼ねる。
別々に2点配る設計ではない。1枚で両方の役割を持つ。安易に2点配布へ戻さないこと。

## 特典とスタンプラリー

**画像を会場で提示 → 当日パンフレット記載のスタンプラリーにスタンプを1つプレゼント。**

このイベントには既存企画としてスタンプラリーがある（スタンプ3つで景品と交換、景品は数に限りあり）。
今回の特典はその **1つ目を先に確保できる** という形。

この設計が効いている理由:

- 台紙が当日パンフレットなので、**会場に来ないと使えない**。特典と来場動機が同一物になる
- 画像をスクショされても転送されても、パンフレットは会場でしか手に入らないので不正利用が成立しない
- 金銭的な割引ではないので、出展者への負担調整・事前合意が要らない

### 提示場所

**会場の受付**で提示してもらう。かんめいさんのブースではない。
画像内の文言もこれに合わせて「受付でご提示ください」と書く。

「お一人さま1回」は運用上の抑止として画像に明記する前提で仕様を書いている。
不要なら画像の文言から外すだけでよい。

## 設問と判定

設問7問。選択肢は上から順に 降三世 / 軍荼利 / 大威徳 / 金剛夜叉 に1点。
**Q7のみ2点。満点8点。**

同点時の優先順位は **軍荼利 → 金剛夜叉 → 大威徳 → 降三世** で固定。
軍荼利を最上位に置くのは、四体でもっとも受け取りやすい結果であるという集客上の判断による。

全16,384通りの回答パターンで検証済み。合計は常に8点、結果分布は
軍荼利 5,191 / 金剛夜叉 4,281 / 大威徳 3,731 / 降三世 3,181。
優先順位どおりに軍荼利がもっとも出やすくなっている。

**設問数の上限は7問。** スマホでこれを超えると完走率が落ちる。増やさないこと。

## 計測

### 発火するイベント

すべて Meta Pixel（ID: `1143852114505095`。他ページと同一）の `trackCustom`。
`fired` フラグで二重発火を防いでいるので、戻る操作をしても同じイベントは再送されない。

| イベント名 | 発火点 | パラメータ |
|---|---|---|
| `PageView` | ページ読み込み | — |
| `MyououStart` | 「診断をはじめる」タップ | — |
| `MyououQ1` 〜 `MyououQ7` | 各設問に回答した時点 | — |
| `MyououComplete` | 結果表示 | `myouou_type` |
| `MyououLineClick` | LINEボタンタップ | `myouou_type` |
| `Lead`（標準） | LINEボタンタップ | — |

### 主要指標の取り方

- **完走率** = `MyououComplete` ÷ `MyououStart`
- **離脱した設問番号** = `MyououQ1` 〜 `MyououQ7` の落差。数字が大きく落ちた設問が改善対象
- **登録転換率** = `MyououLineClick` ÷ `MyououComplete`
- **タイプ分布** = `MyououComplete` を `myouou_type` で分解

`Lead` を標準イベントで併せて撃っているのは、`line/index.html` の計測と揃えて
広告側の最適化に使えるようにするため。

## クーポン画像の仕様（かんめいさん向け）

エネルギーを込めた画像がそのままクーポンを兼ねるため、画像内にクーポン文言が必要になる。

### サイズ・形式

- **1080 × 1080px（正方形）** 推奨。LINEのトーク内でも一覧サムネイルでも切れない
- JPEG または PNG。ファイルサイズは 1MB 以下が目安

### レイアウト

- 上部 3/4：エネルギーを込めた図像部分
- 下部 1/4：クーポン文言の帯。図像と干渉させない
- 会場で受付の人がスマホ画面をひと目で判別できるよう、帯は視認性優先

### 画像内に必ず入れる文言

```
第6回 ぶち癒しフェスタin東京
```

### 書いてはいけないこと

- **効能・効果の断定**。「叶う」「治る」「必ず」「良くなる」等は使わない
- エネルギーについては「不動明王のエネルギーを込めた画像です」までにとどめる
- 割引額・割引率（今回は金銭割引ではない）

## 明王画像

結果画面の上部に、そのタイプの明王の画像を出している。

**ファイル名は明王の漢字名そのまま。`myouou/` 直下に置く。**

| タイプ | ファイル |
|---|---|
| 降三世明王 | `myouou/降三世明王.jpg` |
| 軍荼利明王 | `myouou/軍荼利明王.jpg` |
| 大威徳明王 | `myouou/大威徳明王.jpg` |
| 金剛夜叉明王 | `myouou/金剛夜叉明王.jpg` |

- 名前は `MYOUOU[].name` と完全に一致させること。1文字でも違うと読み込めない
- 拡張子は `.png` `.jpg` `.jpeg` `.webp` のどれでもよい
- `myouou/images/` にローマ字名（`gozanze.png` など）で置いた場合も拾う。予備の経路
- **書き出しは 800×800px・JPEG品質85 程度で十分。1枚200KB前後。**
  表示は幅260pxなので、3倍密度の画面でも800pxあれば足りる。
  元データ（2048px・PNG・1枚9MB前後）をそのまま置くとスマホで開くのが遅くなる。
  差し替えるときは必ず縮小してから置くこと
- **ファイルが無いときは画像の枠ごと出ない。** 4体そろっていなくてもページは壊れない

不動明王（かんめいさんのエネルギー画像）はここには置かない。あれはLINEで配るもので、
サイト上には出さない。

## フォント

本文・見出しとも**明朝**。端末に入っている明朝を優先し、無い端末だけ同梱のwebfontを読む。

```css
font-family: 'Hiragino Mincho ProN', 'Hiragino Mincho Pro',
             'Yu Mincho', YuMincho, 'Noto Serif JP', serif;
```

- iPhone / Mac → ヒラギノ明朝、Windows → 游明朝。**この場合webfontはダウンロードされない**
- Androidは標準で明朝を持たないため、`myouou/fonts/` の Noto Serif JP を読む

### 同梱フォントについて

`fonts/NotoSerifJP-300.woff2`（本文用）と `fonts/NotoSerifJP-600.woff2`（太字用）。
**このページに出る文字だけに絞ってあり、2つで約270KB。**
Google Fontsからそのまま読むと同じ見た目で約1.6MBかかるので、同梱に切り替えている。

ひらがな・カタカナ・英数・約物は全部入れてあるので、多少の文章修正では欠けない。
**新しい漢字を含む文章に書き換えたときは作り直すこと。**入っていない字は
端末側のゴシックで表示される（豆腐にはならないが、そこだけ書体が変わる）。

作り直す手順:

```bash
# 1. Noto Serif JP の Light(300) と SemiBold(600) の ttf を取得
curl -A "Mozilla/4.0" "https://fonts.googleapis.com/css2?family=Noto+Serif+JP:wght@300&display=swap"
curl -A "Mozilla/4.0" "https://fonts.googleapis.com/css2?family=Noto+Serif+JP:wght@600&display=swap"
#    返ってきたCSSの .ttf URL をダウンロードする

# 2. ページに出る文字を集めて subset.txt に入れ、絞り込む
pip install fonttools brotli
python3 -m fontTools.subset NotoSerifJP-300.ttf --text-file=subset.txt \
  --layout-features='*' --flavor=woff2 --output-file=myouou/fonts/NotoSerifJP-300.woff2 --no-hinting
```

## 実装メモ

単一の静的HTML。ビルド不要。`myouou/index.html` を編集してpushすればGitHub Pagesに反映される。
天使診断（`angel/index.html`）と同じ形をとっている。

- 依存ライブラリなし
- 背景は canvas で立ちのぼる火の粉を描画（天使診断の星空にあたる部分）
- 配色は天使診断の紺＋金から、朱＋金へ振っている。シリーズの骨格は維持

### 触るときに注意する箇所

| 箇所 | 注意 |
|---|---|
| `TIE_BREAK` | 同点時の優先順位。変更は企画側の判断が必要 |
| `QUESTIONS[6].weight` | Q7の2点。ここを消すと判定バランスが変わる |
| `QUESTIONS` の要素数 | 7問が上限。増やさない |
| `.funnu-note` | 忿怒相の説明。診断開始より上から動かさない |
| `MYOUOU[].desc` | 事実部分は典拠から逸脱させない |
| `LINE_URL` | 友だち追加URL。全タイプ共通で1本。タイプ別に分けない |
| `MYOUOU[].num` | LINEに送ってもらう番号。応答メッセージ側の登録と必ず揃える |
| `MYOUOU[].img` | `images/` に置く明王画像のファイル名（拡張子なし） |
