# 守護明王診断

第6回 ぶち癒しフェスタin東京（2026年9月19日）の集客企画。
神様診断 → 天使診断 に続くシリーズ三作目。

公開URL: `https://buchiiyashifestatokyo.com/myouou/`

目的は2つ。

1. LINE公式アカウントの友だち登録を増やす
2. イベント来場を促す

導線は 回答完了 → 簡易結果をその場で表示 → LINE登録 → 不動明王のエネルギー画像を配布。

## 設計の芯（崩さないところ）

**四方が結果、中央が特典。**
五大明王は不動明王を中心に、東＝降三世・南＝軍荼利・西＝大威徳・北＝金剛夜叉を配するのが基本形。
この構造をそのまま使い、四方の四体を診断結果、中央の不動明王をプレゼントにしている。
「あなたの明王は四方のどれか。それを束ねる中央に座すのが不動明王」という理屈で、
かんめいさんのエネルギー画像が構成上の五体目になる。

**診断はそれ単体で完結してポジティブに終わる。**
エネルギー画像は結果を高める増幅装置として後から乗る。
画像がないと未完成に見える構成（＝問題を見つけて画像で解決する形）は不採用。

**二段構え。**
診断結果（タイプ名＋説明）はその場で見せる。不動明王のエネルギー画像はLINE登録後。
全部を登録の後ろに隠すと離脱する。全部先に見せると登録する理由が消える。ここは動かさない。

**忿怒相の説明はLPの最上部。**
「怖い顔＝怒り」の印象を先に外しておかないと、結果が前向きに読まれない。
`index.html` の `.funnu-note` がそれ。位置を下げないこと。

**特典は画像1枚のみ。**
かんめいさんのエネルギー画像が、そのまま会場で使えるクーポンを兼ねる。
別々に2点配る設計ではない。1枚で両方の役割を持つ。安易に2点配布へ戻さないこと。

## 特典とスタンプラリー

**画像を会場で提示 → 当日パンフレット記載のスタンプラリーにスタンプを1つプレゼント。**

このイベントには既存企画としてスタンプラリーがある（スタンプ3つで景品と交換、景品は数に限りあり）。
今回の特典はその **1つ目を先に確保できる** という形。

この設計が効いている理由:

- 台紙が当日パンフレットなので、**会場に来ないと使えない**。特典と来場動機が同一物になる
- 画像をスクショされても転送されても、パンフレットは会場でしか手に入らないので不正利用が成立しない
- 金銭的な割引ではないので、出展者への負担調整・事前合意が要らない

### 提示場所

**会場の受付**で提示してもらう。かんめいさんのブースではない。
画像内の文言もこれに合わせて「受付でご提示ください」と書く。

「お一人さま1回」は運用上の抑止として画像に明記する前提で仕様を書いている。
不要なら画像の文言から外すだけでよい。

## 設問と判定

設問7問。選択肢は上から順に 降三世 / 軍荼利 / 大威徳 / 金剛夜叉 に1点。
**Q7のみ2点。満点8点。**

同点時の優先順位は **軍荼利 → 金剛夜叉 → 大威徳 → 降三世** で固定。
軍荼利を最上位に置くのは、四体でもっとも受け取りやすい結果であるという集客上の判断による。

全16,384通りの回答パターンで検証済み。合計は常に8点、結果分布は
軍荼利 5,191 / 金剛夜叉 4,281 / 大威徳 3,731 / 降三世 3,181。
優先順位どおりに軍荼利がもっとも出やすくなっている。

**設問数の上限は7問。** スマホでこれを超えると完走率が落ちる。増やさないこと。

## 計測

### 発火するイベント

すべて Meta Pixel（ID: `1143852114505095`。他ページと同一）の `trackCustom`。
`fired` フラグで二重発火を防いでいるので、戻る操作をしても同じイベントは再送されない。

| イベント名 | 発火点 | パラメータ |
|---|---|---|
| `PageView` | ページ読み込み | — |
| `MyououStart` | 「診断をはじめる」タップ | — |
| `MyououQ1` 〜 `MyououQ7` | 各設問に回答した時点 | — |
| `MyououComplete` | 結果表示 | `myouou_type` |
| `MyououLineClick` | LINEボタンタップ | `myouou_type` |
| `Lead`（標準） | LINEボタンタップ | — |

### 主要指標の取り方

- **完走率** = `MyououComplete` ÷ `MyououStart`
- **離脱した設問番号** = `MyououQ1` 〜 `MyououQ7` の落差。数字が大きく落ちた設問が改善対象
- **登録転換率** = `MyououLineClick` ÷ `MyououComplete`
- **タイプ分布** = `MyououComplete` を `myouou_type` で分解（LINE側では判別しないので、分布が見えるのはここだけ）

`Lead` を標準イベントで併せて撃っているのは、`line/index.html` の計測と揃えて
広告側の最適化に使えるようにするため。

## クーポン画像の仕様（かんめいさん向け）

エネルギーを込めた画像がそのままクーポンを兼ねるため、画像内にクーポン文言が必要になる。

### サイズ・形式

- **1080 × 1080px（正方形）** 推奨。LINEのトーク内でも一覧サムネイルでも切れない
- JPEG または PNG。ファイルサイズは 1MB 以下が目安

### レイアウト

- 上部 3/4：エネルギーを込めた図像部分
- 下部 1/4：クーポン文言の帯。図像と干渉させない
- 会場で受付の人がスマホ画面をひと目で判別できるよう、帯は視認性優先

### 画像内に必ず入れる文言

```
第6回 ぶち癒しフェスタin東京
2026年9月19日（土）会場受付でご提示ください

スタンプラリー スタンプ1つ進呈

有効期限：2026年9月19日 当日限り
お一人さま1回
```

### 書いてはいけないこと

- **効能・効果の断定**。「叶う」「治る」「必ず」「良くなる」等は使わない
- エネルギーについては「不動明王のエネルギーを込めた画像です」までにとどめる
- 割引額・割引率（今回は金銭割引ではない）

## 実装メモ
